## Лабораторная работа №1. Представление данных

**Суть:** Ввод числа и вывод его внутреннего двоичного представления, а также циклический сдвиг битов.
**Модернизация:** Вместо ручного вывода через указатели в стиле С, использован класс `std::bitset` и типы данных фиксированной длины из `<cstdint>`. Типы данных по варианту (8): `long` (64 бита) и `double` (64 бита).

**Как собрать и запустить:**
1. Откройте терминал (или консоль MSYS2/WSL) в папке с файлом `main.cpp`.
2. Скомпилируйте (команда одинакова для всех ОС):
   `g++ main.cpp -o lab1`
3. Запустите:
   * В Linux/macOS: `./lab1`
   * В Windows (MSYS2): `./lab1.exe`

## Лабораторная работа №3. Видеосистема (графический режим)

**Суть:** Построение графика функции `sin³(x) + cos²(x)` на интервале `[3π/2, 8π]` с осями, подписями и поиском максимума.
**Модернизация:** Устаревший BGI (`graphics.h`) заменен на библиотеку **SDL2** и модуль вывода текста **SDL2_ttf**.

**Подготовка зависимостей (ВАЖНО!):**
Перед сборкой установите SDL2:
*   **Linux (Ubuntu/Debian):** `sudo apt install libsdl2-dev libsdl2-ttf-dev pkg-config`
*   **macOS (через Homebrew):** `brew install sdl2 sdl2_ttf pkg-config`
*   **Windows (MSYS2 MinGW64):** `pacman -S mingw-w64-x86_64-SDL2 mingw-w64-x86_64-SDL2_ttf pkg-config`

**Как собрать и запустить:**
1. Откройте терминал в папке с файлом. Убедитесь, что файл шрифта `LiberationSans-Regular.ttf` лежит в той же папке.
2. Скомпилируйте:
   * **Для Linux/macOS:**
     `./build.sh`
   * **Для Windows (MSYS2):**
     `./build.bat`
3. Запустите: `./lab3` или `./lab3.exe`.

## Лабораторная работа №4. Клавиатура и прерывания

**Суть:** Две программы, которые двигают символ `*` по экрану, используя разные подходы к вводу.
**Модернизация:** Эмуляция DOS-прерываний (`INT 9`, `INT 16h`). Вместо `getch()` и буфера BIOS используется POSIX-функция `termios` и **многопоточность C++** (`std::thread`, `std::mutex`, `std::condition_variable`).
*   `program1.cpp` — использует прямой небуферизованный ввод через `termios` (высокоуровневый подход).
*   `program2.cpp` — использует фоновый поток-производитель и поток-потребитель (очередь) для имитации работы контроллера прерываний.

**Как собрать и запустить:**
*Внимание: программа использует POSIX-вызовы (`termios`), поэтому НЕ компилируется в нативном Windows. Используйте WSL или Linux/macOS.*
1. Откройте терминал в папке с файлами.
2. Скомпилируйте первую программу:
   `g++ program1.cpp -o prog1`
3. Скомпилируйте вторую программу:
   `g++ program2.cpp -o prog2`
4. Запустите: `./prog1` или `./prog2`. 
   *Управление:* стрелки вверх/вниз. *Выход:* клавиша `q`.

## Лабораторная работа №5. Аппаратные прерывания

**Суть:** Перехват реального аппаратного прерывания.
**Модернизация:** Вместо написания DOS-программы с `getvect`/`setvect`, написан **загружаемый модуль ядра Linux**. Он регистрирует свой обработчик (`request_irq`) на линии IRQ 24 (USB-контроллер) с флагом `IRQF_SHARED` (разделение прерывания с системным драйвером).

**Подготовка (ВЫПОЛНЯТЬ ТОЛЬКО В LINUX / WSL):**
1. Установите компилятор и заголовки текущего ядра:
   `sudo apt update`
   `sudo apt install build-essential linux-headers-$(uname -r)`
2. *(Опционально)* Если в системе включен механизм MSI (Message Signaled Interrupts) и ядро не дает занять линию, добавьте параметр загрузки `pci=nomsi` в файл `/etc/default/grub` (в строку `GRUB_CMDLINE_LINUX_DEFAULT`), затем выполните `sudo update-grub` и перезагрузитесь.

**Как собрать и запустить:**
1. Откройте терминал в папке с файлами `driver_for_keyboard.c` и `Makefile`.
2. Скомпилируйте модуль: `make`
3. Откройте второй терминал и смотрите системные логи в реальном времени:
   `sudo dmesg -w`
4. Загрузите драйвер в ядро:
   `sudo insmod driver_for_keyboard.ko`
5. Понажимайте клавиши на клавиатуре, чтобы увидеть, как растет счетчик прерываний в логах.
6. Выгрузите драйвер: `sudo rmmod driver_for_keyboard`
